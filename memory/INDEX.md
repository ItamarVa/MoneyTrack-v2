## Git remotes — read before any push

**Work on the private repository only: `origin` → `ItamarVa/MoneyTrack`, branch `master`.** Commit, push and pull there as usual. Commits are authored as the GitHub noreply address — the owner's work address goes on no new commit, private or public — enforced both repo-locally and by `includeIf` rules in `~/.gitconfig` that survive a re-clone (MEM-PUB).

**A public repository also exists — `public` → `ItamarVa/MoneyTrack-v2`, branch `main` — and nothing may be pushed to it without an explicit current instruction from the owner plus the pre-flight check in MEM-PUB.** It holds one orphan commit with no ancestor in common with `master`, which is the only thing keeping the owner's work email and the pre-scrub personal data out of public view. So: never `git push public master`, never merge or pull between `main` and `master`, and never commit routine work while `main` is checked out — that branch pushes straight to the public repo. A public push cannot be undone; forks, caches and search engines keep what lands there. Full procedure and rationale: [publishing.md](./publishing.md) (MEM-PUB), ADR-006.

## Conventions

- Public brand names (chains, services) may appear in seed rules even when they also occur in the owner's statements; allowlist their hashes with an owner-approved comment (owner 2026-11-04). Personal names, payees, amounts and account numbers never.
- zod GHSA-mrhx-c7xc-m3w5 accepted until 2026-12-26 (owner 2026-11-04); real fix = zod 4 migration + puppeteer 25 upstream.
- Phone-first (owner 2026-11-04): the main user works on a phone; every change is designed for and visually verified at 375px before release, inside the real Home Assistant frame (HA top bar + sidebar around the add-on iframe), not only standalone. Chart taps first reveal what was tapped; drilling down needs a second, explicit action.
- Test fixtures, examples and docs use synthetic data only — never values copied from real statements or the DB. `npm run privacy:check` enforces it before any public snapshot (MEM-PUB).
- HA master passphrase: min 8 + lower/upper/digit/special + denylist (owner 2026-09-28); max 256, rule in `@moneytrack/contracts`, enforced by `checkHaPassphrase()` (ADR-008).
- HA screens say "master password" (owner 2026-09-28, Hebrew copy in `he.json`); code, API fields and error codes keep "passphrase". HA denylist also checks digit/symbol-stripped and de-leeted cores (4+ chars); desktop unchanged.
- New Hebrew UI copy goes in `apps/web/src/locales/he.json`, never inline in source; older screens are not migrated (MEM-ARCH).
- Releases (owner 2026-11-08): Claude publishes to `public` itself (owner-granted permission in `MoneyTrack v2/.claude/settings.local.json`), dispatches the image and installs the update in HA; the owner only enters the master password and PIN. Personal merchant rules and account owners are set in the live app via the API, not in code.
